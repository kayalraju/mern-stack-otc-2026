Cascading Style Sheets (CSS) is a rule-based stylesheet language used to specify the presentation, layout, and visual formatting of documents written in a markup language like HTML or XML. Along with HTML (which provides the structure) and JavaScript (which provides behavior and logic), CSS is one of the three cornerstone technologies of the World Wide Web
